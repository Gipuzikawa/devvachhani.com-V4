# Superpowers

`specs/` holds approved designs — the durable record of what was decided and why. `plans/` holds
the implementation plans built from those specs — the task-by-task breakdown of how each one gets
done. Both are committed. See `docs/build/workflow.md` for how work moves from brainstorm through
spec, plan, execution, review, and finish.

For the current Sanity implementation checkpoint and next-session instructions,
see [the Sanity handoff](../sanity/session-handoff.md). The approved overall design
and phased implementation plan remain the authority for future phases.
